## 🚀 Featured work (2026)

### 🎥 Make your website agent ready with WebMCP — Google Cloud Tech
Talk on the official Google Cloud Tech channel: how to expose typed tools inside web pages so AI agents act reliably, faster and with far fewer tokens. Includes a live demo of a data developer portal powered by Gemini.

> 🎥 [Watch on YouTube](https://www.youtube.com/watch?v=FARxSG_EY98) (28K+ views) · 💻 [webmcp-happy-coffee](https://github.com/hugozanini/webmcp-happy-coffee)

### 📰 Moving Beyond Screen Scraping: an agent-native web app with WebMCP
A complete React travel-booking app where search, discovery and booking are exposed as structured tools. The agent completes the full flow with 100% determinism and much lower token cost than DOM scraping.

> 📰 [Article](https://medium.com/data-science-collective/moving-beyond-screen-scraping-creating-an-agent-native-web-app-with-webmcp-4818552e1e11) · 💻 [air-bird-booking-web-mcp](https://github.com/hugozanini/air-bird-booking-web-mcp)

### 📰 Nano: an AI grocery assistant, and the lakehouse under it
A WhatsApp assistant built with Gemini function calling, Firestore for live shopping lists and a BigQuery + Apache Iceberg lakehouse for purchase history. Unanswered questions are logged and turned into feature requests, so the product improves itself.

> 📰 [Article](https://medium.com/data-science-collective/nano-an-ai-grocery-assistant-and-the-lakehouse-under-it-174f6d0343b2) · 💻 [nano](https://github.com/hugozanini/nano)
